## What this settles

The repository previously held two contradictory statements: one report claiming the original parts contained zero solid bodies and another claiming one solid body each. Both referred to superseded files. The current part set is new geometry built by script, and every part above reports exactly one solid body, no surface bodies, and a bounding box whose dimensions are physically meaningful for its role in the fan.

## Limits of this evidence

- Solid-body counts and boxes come from `IPartDoc.GetBodies2` and `IBody2.GetBodyBox`, not from file sizes or filenames.
- The parts carry no assigned SOLIDWORKS material, so SOLIDWORKS' own mass property uses the 1000 kg/m3 default. The masses in this report use the stated design densities instead and are therefore CAD-derived volume x assumed density, not a material-assigned mass.
- No aerodynamic or structural validation is implied.
